  rpool import <artifact-root> --age-identity <identity-file> --dry-run

Artifact layout:
  <artifact-root>/config/portable-config.json
  <artifact-root>/secrets/rclone.age

Security properties:
- portable JSON contains no crypt passwords
- vault stores only already-obscured rclone password/password2 values under age encryption
- no crypt password deobscure/reveal API
- no plaintext secret temp file in the export path
- vault ciphertext is BLAKE3-bound to the portable JSON to reject mixed exports
- import validates before mutation and uses transactional rclone config restoration
- age identity/private key must remain outside the portable artifact root
- provider credentials/tokens are outside this feature

Generation policy:
- new crypt secret generation uses independent 1024-bit OS randomness for password and password2 per remote
- export/import never rotates existing keys and never invents password2 for an existing remote

Compatibility:
- legacy `rpool config export/import` remains JSON-only and refuses crypt-aware bundles
- target import rclone.conf must already contain matching named crypt remotes and their non-secret structure
- rclone config path is discovered with `rclone config file` unless --rclone-config is supplied
- import derives the public recovery-snapshot recipient from --age-identity with age-keygen unless --age-recipient is supplied
